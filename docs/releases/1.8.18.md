# Orka 1.8.18

Orka 1.8.18 begins the disposable phase-worker epic in issue #78 and completes
its protocol slice in issue #112.

## Changed

- Defines the provider-neutral `orka.phase-worker-protocol/v1` boundary between
  the durable supervisor and disposable AI phase executions.
- Requires a fresh model context for every dispatch while permitting host
  process reuse without retained model state.
- Binds jobs, progress, heartbeats, cancellation, acknowledgements, and terminal
  results to immutable attempt, dispatch, execution-unit, and supervisor-fence
  identities.
- Carries typed branch, PR, revision, tree, and artifact references while
  requiring the supervisor to verify them externally before state mutation.
- Adds capability negotiation profiles for Codex desktop, Claude desktop, and
  API adapters, with fail-closed mandatory capability checks.
- Classifies malformed, unsupported, stale, and unacknowledged-cancellation
  failures without granting them global-stop authority.
- Documents the compatibility mapping from current controller evidence to the
  protocol identity fields.

## Verification

- Shared provider-neutral positive and negative adapter fixtures.
- Direct contract validation for immutable envelope identity sets.
- Rejection coverage for missing fencing, resumed conversations, stale fences,
  missing adapter profiles, unknown outcomes, and unsupported versions.
- Additive optional-capability negotiation coverage.
- Full repository regression suite.
