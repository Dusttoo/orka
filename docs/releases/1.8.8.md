# Orka 1.8.8

Orka 1.8.8 adds durable, capacity-aware resource admission to the host-owned
sprint supervisor.

## Added

- Versioned `orka.resource-claims/v1` contract for repository, ticket, PR,
  worktree, migration, provider-route, visual-QA, and heavy-process resources.
- Non-consuming conflict checks that continue admitting independent work in
  controller priority order.
- Same-cycle claim accounting, durable claim digests, exact-once terminal
  release receipts, and restart reconstruction.
- Optional exclusive migration, provider-route, and visual-QA claims from
  authenticated Jira labels.
- Independent enforcement of the existing `max_heavy_processes` setting.

## Compatibility

Existing configuration remains valid. Active jobs from earlier 1.x supervisor
snapshots receive deterministic automatic claims without resetting attempts or
worker identity. Malformed or inconsistent durable claims fail closed.
