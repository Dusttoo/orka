# Orka 1.8.22

Orka 1.8.22 rejects `PASS` reviews that declare zero checks in
`validate_review_output`, closing the gap tracked by issue #49.

## Fixed

- `PASS` verdicts with an empty `checks` array are rejected for both
  `code-review` and `security-review` gates.
- Regression coverage in `tests/context-pipeline.test.sh` asserts the
  fail-closed behavior for empty-check `PASS` reviews.

## Compatibility

- Existing `PASS` reviews that already include at least one check are
  unchanged.
- No configuration migration is required. The optional per-gate
  `min_review_checks` suggestion from #49 is not implemented.
