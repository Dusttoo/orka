# Orka 1.8.16

Orka 1.8.16 delivers the sprint pressure and hard global breaker slice of
issue #75.

## Predictable sprint admission

- Classifies unfinished-PR, lane-capacity, and heavy-process pressure as soft
  sprint breakers.
- Uses `degraded` only for sprint pressure; route-local holds no longer change
  global supervisor state.
- Preserves active workers while existing queue and capacity rules reduce new
  admission.
- Pauses for unavailable routes only when every role required by otherwise
  eligible work is actually held.

## Generation-bound global breakers

- Binds all-routes, hard sprint budget, preflight, lease, and durable-state
  failures to canonical sprint breaker records.
- Gives each activation a durable generation and makes duplicate delivery a
  no-op.
- Restores the exact pressure or pause generation after an authenticated
  unclean takeover.
- Requires a fresh authoritative budget receipt plus an operator resume bound
  to the exhausted generation before hard-budget admission can restart.
- Preserves queued, parked, and running work across every global transition.

Checkpoint migration and the final cross-version status/restart matrix remain
the next independent issue slice.
