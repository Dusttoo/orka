# Orka 1.5.4 — visual-QA navigation reconciliation

Visual QA now reconciles same-step Next.js App Router request failures after the
navigation settles. An aborted same-origin RSC request is ignored only when a
later RSC request for the exact same origin and pathname finishes successfully,
the destination reaches its expected state, and no page error occurs. The
manifest retains ignored-request evidence for auditability.

Document-navigation aborts, missing or failed retries, cross-origin and
cross-path replacements, non-RSC failures, HTTP failures, and page errors remain
blocking.

The visual-QA role contract now distinguishes public direct-route checks from
private, unlisted, and entry-gated flows. Private surfaces must be captured
through their authorized entry path or with repository-provided visibility and
authentication settings; their expected fail-closed direct response is not a
feature regression.
