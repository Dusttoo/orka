# Orka 1.8.21

Orka 1.8.21 implements the transactional event-store core tracked by issue
#116 and accepted in ADR 0001.

## Added

- A supervisor-owned, repository-locked SQLite writer with bounded
  `BEGIN IMMEDIATE` transactions.
- Atomic job creation, reservation, launch, completion, resource claims, retry
  timers, and external-operation intent/receipt transitions.
- Append-only canonical events and transactionally maintained projections with
  optimistic aggregate versions and exact idempotency replay.
- A versioned, digest-bound migration runner plus explicit WAL version/local
  filesystem gating and rollback-journal status.
- API-level concurrency and stale-writer tests covering jobs, events, claims,
  timers, and external receipts.

## Compatibility

- The existing JSON controller checkpoint remains authoritative.
- No existing controller, supervisor, worker, import, or merge path opens or
  writes the new database in this release.
- Deterministic export/import and production cutover remain separate reviewed
  slices.
