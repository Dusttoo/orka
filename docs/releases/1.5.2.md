# Orka 1.5.2

## Recovery checkout binding

- Preserved-PR recovery workers now start in the exact worktree authenticated
  by the controller's recovery binding.
- Caller-provided Codex `--cd` arguments are removed and replaced with the
  controller-owned checkout.
- The supervisor independently verifies that the selected checkout belongs to
  the managed Git repository before spawning the worker.

## Repository runtime floor

- Repositories may set `minimum_orka_version` in orchestration configuration.
- Captain preflight fails closed when the active stable release is older than
  that minimum while accepting local cachebuster suffixes on the same release.
