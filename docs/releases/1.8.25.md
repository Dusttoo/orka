# Orka 1.8.25

Orka 1.8.25 clarifies how fork contributors satisfy the protected branch's
signed-commit rule and how maintainers assign plugin versions at merge time.

## Changed

- Documented GPG and SSH commit signing, local inspection, GitHub verification,
  and recovery from unsigned commits.
- Moved final version selection, paired manifest updates, and release-note
  ownership from contributors to maintainers.
- Clarified that the marketplace uses the paired manifest version on `main`
  while GitHub Releases are tagged source snapshots.
- Added a maintainer release checklist covering signed tags and GitHub Releases.

## Compatibility

No runtime behavior, configuration, or data migration changes.
