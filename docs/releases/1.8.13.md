# Orka 1.8.13

Orka 1.8.13 completes the evidence-backed recovery epic with deterministic
crash-boundary and replay proofs.

## Added

- A machine-readable recovery crash-boundary matrix declaring durable state,
  next action, and external-effect policy for nine recovery boundaries.
- Credential-free fault injection for pre-commit recovery crashes,
  post-fence replay, worker reservation/attach replay, and independent queue
  progress around an ineligible recovery.
- Compact committed transition traces for dead-worker and preserved-PR
  recovery.

## Fixed

- Preserved-PR recovery fence IDs are now derived from authenticated recovery
  evidence instead of generated randomly.
- Replaying the same fence is idempotent; a different active fence fails closed
  rather than silently superseding the original boundary.

## Safety

The fault matrix uses only local fixtures. Recovery still cannot grant budget,
review, repair, security, Jira-transition, or merge authority. Ambiguous
provider acknowledgement remains an operator decision, and every existing
attempt, spend, progress, PR, worktree, finding, and review-generation binding
remains monotonic.
