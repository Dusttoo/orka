# Orka 1.8.26

Orka 1.8.26 documents the founder-first one-year product vision and future-state
system design tracked by issue #147.

## Documentation

- Defines Orka's primary operator, one-year promise, principles, autonomy
  boundary, deployment modes, success measures, and explicit non-goals.
- Describes a durable control plane whose supervisor and context survive model,
  provider, control-surface, and worker changes.
- Adds a Mermaid system diagram covering the CLI and browser, transactional
  supervisor, policy and scheduling, external adapters, replaceable model
  routes, and capacity-aware local or ephemeral workers.
- Maps the vision to the Orka 2.0 foundation, production-hardening, and platform
  evolution issue groups.

## Compatibility

- This release changes documentation only. Runtime behavior and configuration
  remain unchanged.
