# Orka 1.8.17

Orka 1.8.17 completes the breaker integration epic in issue #75 and the final
delivery slice in issue #106.

## Changed

- Migrates authenticated supervisor schema-v1 state exactly once into schema
  v2 with a content-addressed compatibility receipt.
- Preserves dispatch jobs, attempt and execution-unit bindings, spend, review
  and PR references, dependencies, operator requests, and lifecycle history.
- Rejects unknown or ambiguous legacy stops and any migration that would
  soften a protected budget, review, security, or merge control.
- Reclassifies legacy route-only degradation as a local route hold rather than
  retaining an obsolete global lifecycle transition.
- Publishes stable queued, active, retrying, parked, route-held,
  pressure-limited, globally paused, blocked, and terminal status categories.
- Counts only completed, decomposed, or cancelled jobs as terminal.

## Verification

- Offline schema-v1 migration and idempotent replay fixtures.
- Authenticated unclean-restart migration across runtime fingerprints.
- Unknown-stop and unsafe hard-control reclassification failures.
- Existing breaker, lifecycle, controller, dispatch, admission, recovery, and
  full repository regression suites.
